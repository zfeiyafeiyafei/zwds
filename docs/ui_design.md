# 紫微斗数平台界面设计规划（UI/UX Design V1）

> 定位：本文档是界面层的顶层设计，与 `biz_requirement.md`（功能需求）、`architecture.md`（系统架构）并列。
> 功能决定"做什么"，本文档决定"如何呈现与组织"。

## 1. 现状诊断

当前界面（2026-09）在功能快速叠加后暴露以下结构性问题：

### 1.1 导航层级混乱

- **两层页签并存**：功能页签（排盘 / AI 分析）与视图页签（传统宫格 / 时钟圆盘）都是胶囊切换组，视觉权重相同、语义层级不同，用户难以建立心智模型
- 运限日期导航、复制 JSON、主题切换、AI 设置全部挤在工具栏，一级操作与设置操作无区分
- 新功能（合盘、报告、知识库）没有可落位的导航位置，继续加页签会失控

### 1.2 空间分配不合理

- 命盘是核心对象，却只拿到 `100% - 260px - 340px - 340px` 的剩余宽度；格局、星曜两个固定栏各 340px 喧宾夺主
- 左栏把"数据"（已有命盘）与"操作"（排盘表单）两种不同心智的内容堆叠在一起
- 排盘表单是低频操作（建盘一次），却常驻占据最贵的首屏左侧

### 1.3 扩展性缺失

- 规划中的功能（运限四化叠加、三方四正高亮、图片导出、主题系统、合盘、流月流日）在现有布局中没有预设的 UI 落点
- 响应式只有一个断点（1600px）的临时处理，没有完整的断点体系

### 1.4 视觉语言不统一

- 已有良好的设计令牌基础（`style.css`：纸墨底色 + 靛蓝强调 + 朱砂主星红），但组件级样式各自为政：按钮 6 种写法、面板边框/圆角/阴影组合不一致
- 无排版尺度（type scale）与间距尺度（spacing scale），字号 11/12/13/14px 随意分布

---

## 2. 设计原则

1. **命盘中心**：排盘工作台中，命盘画布永远占据视觉与空间的中心；分析面板是辅助，默认让位
2. **渐进呈现**：低频操作（建盘表单、设置）收进抽屉/模态；高频信息（命盘、运限、分析）常驻
3. **单一导航源**：全局导航只有一处（左侧导航栏），页签只允许出现在视图内部，且不超过一层
4. **令牌先行**：新样式只消费 `style.css` 设计令牌，不新增硬编码色值/圆角/阴影
5. **布局与数据解耦**：延续主题系统原则（biz §5.4），布局切换不触碰数据流

## 3. 信息架构

### 3.1 导航模型：左侧应用导航栏（Nav Rail）

用 64px 宽的图标导航栏替代顶部功能页签，承载全部一级功能与全局操作：

```
┌────┐
│ 卍 │  品牌标识（点击回排盘）
│    │
│ 📊 │  排盘工作台（默认页）
│ 🤖 │  AI 分析
│ 💞 │  合盘          ← 规划功能预留位
│ 📑 │  分析报告      ← 规划功能预留位（AI 报告存档）
│ 📚 │  知识库        ← 远期预留位
│    │
│ ⭘  │  主题切换（底部区）
│ ⚙  │  设置（底部区）
└────┘
```

规则：

- 导航栏是**唯一**的全局导航；当前功能项图标加左侧 2px 强调色指示条
- "排盘/AI 分析"页签组删除，其功能由导航栏接管
- 设置保持模态对话框（现有 AISettingsDialog 演化），不单独占导航项以外的层级

### 3.2 视图内层级

每个一级功能是一个"工作台"（Workspace），内部最多再分一层：

| 工作台 | 内部结构 |
| --- | --- |
| 排盘 | 画布区（宫格/圆盘切换 = 画布右上角视图控件，不再是页签）+ 洞察栏（内部 tab） |
| AI 分析 | 会话区 + skill 选择（改为会话顶部 chip 行） |
| 合盘（规划） | 双盘选择器 + 并排画布 + 关系分析栏 |
| 报告（规划） | 报告列表 + 阅读视图 |

## 4. 排盘工作台布局

### 4.1 三列结构（宽屏 ≥1440px）

```
┌──────┬────────────────┬──────────────────────┬──────────────┐
│ Nav  │   数据栏        │      命盘画布          │   洞察栏      │
│ Rail │   280px        │      自适应（≥560px）  │   360px      │
│ 64px │                │                      │              │
│      │ ┌────────────┐ │ ┌──────────────────┐ │ ┌──────────┐ │
│      │ │ 已有命盘检索 │ │ │ 卡片头：          │ │ │ tab:     │ │
│      │ │            │ │ │ 运限导航·四化开关  │ │ │ 格局|星曜 │ │
│      │ ├────────────┤ │ │ 布局·导出·复制    │ │ │ [周期]   │ │
│      │ │ ＋ 新建命盘 │ │ ├──────────────────┤ │ ├──────────┤ │
│      │ │  (折叠表单) │ │ │                  │ │ │          │ │
│      │ └────────────┘ │ │    命 盘 画 布     │ │ │ 分析内容  │ │
│      │  可整栏折叠     │ │    （居中最化）     │ │ │          │ │
│      │                │ └──────────────────┘ │ └──────────┘ │
└──────┴────────────────┴──────────────────────┴──────────────┘
```

关键决策：

1. **洞察栏合并**：格局分析与星曜解析从"左右两个固定栏"合并为右侧单一 360px 栏，内部 tab 切换（格局 | 星曜；预留"周期"位给 §4.3.3 周期解读）。命盘可用宽度净增 340px
2. **排盘表单抽屉化**：数据栏默认只显示"已有命盘检索 + ＋新建命盘"按钮；点击后表单从左侧滑出覆盖数据栏（不改路由）。当前已保存盘的出生信息以只读摘要呈现，编辑走现有编辑对话框
3. **命盘卡片化**：画布收进一张卡片，卡片头集中承载：运限日期导航（‹ 日期 › + 虚岁/大限 chip）、运限四化叠加开关（规划项 §5.8）、布局切换（宫格/圆盘图标按钮组）、复制 JSON、导出（JSON/图片，预留 PNG 位）
4. **三方四正高亮**（规划项）：点击宫位时画布内联动高亮，不需要额外面板空间

### 4.2 中断点（1280–1439px）

- 洞察栏收窄至 320px，数据栏可折叠为 48px 图标条

### 4.3 窄断点（<1280px，如 1080p 窗口）

- 洞察栏转为**右侧抽屉**：默认收起，命盘卡片头提供"洞察"按钮滑出；抽屉覆盖画布而非挤压
- 数据栏整栏抽屉化（导航栏保留）

### 4.4 移动断点（<760px，为 Web 移动版与 Flutter 参考）

- 单列：命盘全宽，洞察/数据均为底部抽屉；圆形布局优先（biz §5.7）

## 5. AI 分析工作台

```
┌──────┬───────────────────────────────────────────────────┐
│ Nav  │  ┌─────────────────────────────────────────────┐  │
│ Rail │  │ 会话头：当前命盘 chip（点击定位排盘）· 清空 · ⚙ │  │
│      │  ├─────────────────────────────────────────────┤  │
│      │  │ skill chips：[总体][性情][事业][财富][感情]…   │  │
│      │  ├─────────────────────────────────────────────┤  │
│      │  │                                             │  │
│      │  │              对 话 流（流式渲染）             │  │
│      │  │                                             │  │
│      │  ├─────────────────────────────────────────────┤  │
│      │  │ 追问输入框                            [发送] │  │
│      │  └─────────────────────────────────────────────┘  │
└──────┴───────────────────────────────────────────────────┘
```

关键决策：

1. **Skill 下拉改为 chip 行**：内置 skill 是一组并列动作，chips 比下拉少一次点击、可一目了然；自定义 skill 追加在后（超出折叠为"更多"）
2. **会话头命盘 chip**：显示当前对话所属命盘（姓名 + 生辰），点击跳回排盘工作台定位该盘；历史 by 命盘机制不变
3. 对话流最大宽度 760px 居中，避免长行阅读疲劳
4. 输入框固定底部，支持 Shift+Enter 换行

## 6. 设置与模态体系

- 设置（LLM 配置 / skill 管理）保持单一模态，从导航栏底部 ⚙ 进入；后续增加"外观"区（主题选择，对接主题系统 biz §5）
- 所有模态统一：居中、遮罩 `var(--mask)`、Esc 关闭、焦点圈定（focus trap）

## 7. 视觉规范

### 7.1 令牌层（已有，保持）

`style.css` 的色板/圆角/阴影/光环令牌继续作为唯一来源；暗色主题对称覆盖。

### 7.2 排版尺度（新增约束）

| 角色 | 字号/行高 | 用途 |
| --- | --- | --- |
| display | 18/28 600 | 命盘卡片标题、对话框标题 |
| body | 13/20 400 | 正文、按钮、表单 |
| caption | 12/16 400 | 辅助说明、徽标 |
| micro | 11/14 400 | 星曜小字、宫位元信息 |

### 7.3 间距尺度

4 的倍数：4 / 8 / 12 / 16 / 24。面板内边距 16，卡片内边距 20，栏间距 16。

### 7.4 组件收敛

- 按钮收敛为三种：`primary`（强调填充）、`ghost`（描边）、`icon`（30px 方图标）。现有 `copy-btn`、`period-nav button`、`row-btn`、`theme-toggle` 全部归并
- 面板收敛为一种：白底 + `--line` 边框 + `--radius` + `--shadow-sm`

### 7.5 动效

- 仅允许 150–200ms 的 opacity/transform 过渡；主题切换已有全局过渡，保持不变
- 抽屉滑出 200ms ease-out；不用弹跳曲线
